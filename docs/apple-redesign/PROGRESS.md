# Apple redesign — progress log

One line per converted screen or phase: what changed. Branch: `feature/apple-design`.

- **Phase 0** — Baseline commit of `mobile/` + `.claude/skills/`; audit written to `AUDIT.md` (baseline `flutter analyze`: 4 infos).
- **Phase 1** — `lib/core/design/` tokens: semantic `CupertinoDynamicColor`s (iOS system neutrals + teal accent), HIG type scale (Cairo titles, SF body on Apple platforms, Scheherazade Quran), 4-pt spacing, radii with continuous corners, 44-pt target. `AppTheme` = `CupertinoThemeData` + iOS-platform Material theme on the same tokens; `core/theme/*` re-export; `main.dart` gains `builder: AppTheme.builder`. New `test/design_theme_test.dart` (light / dark / system resolution). Analyze: 3 pre-existing infos.
- **Phase 2** — Component library in `lib/core/design/widgets/` (barrel `core/design/design.dart`): `AppScaffold` (standard + large title with bottom slot and pull-to-refresh), `AppNavBar`, `AppTabBar`/`AppTabScaffold`, `AppButton` (filled/tinted/plain/destructive, loading, haptics), `AppIconButton`, `AppCard` (spring press, no shadow, continuous corners), `AppIconTile`, `AppListSection`/`AppListTile`, `AppSwitch`, `AppSegmentedControl`, `AppTextField`/`AppTextFormRow`/`AppSearchField`, `showAppDialog`/`showAppTextInputDialog`/`showAppActionSheet`/`showAppSheet`/`showAppBottomSheet`/`showAppPicker`/`showAppDatePicker`, `AppToast`, `AppLoader`/`AppRefreshSliver`/`AppEmptyState`/`AppProgressBar`, RTL helpers (`AppDirectionalIcon`, `LtrText`, `ltr()`), `AppMotion`. `ErrorRetry` now renders through `AppEmptyState`. `main.dart` uses `CupertinoScrollBehavior` (bouncing, no Android glow). `DesignSystemPreview` + `test/design_system_preview_test.dart` (light/dark × RTL/LTR, 1.6× text, overlays). Found and handled: `CupertinoIcons.chevron_*` don't mirror in RTL; google_fonts needs `.weight()` instead of `copyWith(fontWeight:)`.
- **Phase 3** — Router: every route now builds a `CupertinoPage` via `pageBuilder` (edge swipe-back, from the right in RTL); paths, params and shell branches unchanged; debug-only `/__design` route for `DesignSystemPreview`. `MainShell` → `AppTabScaffold` + `AppTabBar` (iOS tab bar, CupertinoIcons, selection haptic); provider watches and `goBranch(initialLocation:)` untouched. Tab bar + mini-player height reach pages as `MediaQuery` bottom padding, so the 8 manual `GlassNavigationBar.totalHeight()` paddings are gone (fixes the double-counted inset). Both mini-players render through the new `AppMiniPlayerBar` (blur, hairline, no shadow, one `reservedHeight` token instead of 64 / 80); their provider / controller calls are unchanged. Removed the now-unused private `_NowPlayingBar` and `_RoundButton` (Material `InkWell`) from `mp3quran_player_screen.dart`. `GlassNavigationBar` is unused (deletion pending approval). No FABs existed.
- **Screen 1 · Splash + Account** — Splash: tokens instead of `Colors.white`, no letter-spacing on the Arabic wordmark, light status bar, honours Reduce Motion, logo mark exempt from text scaling; delay + `go('/home')` unchanged. Account: `AppScaffold` with standard nav bar title and the system back chevron (a "Home" button when there is no history, same as before); form as inset-grouped `AppTextFormRow`s in an `AutofillGroup`, e-mail / password LTR, eye toggle with a state-correct label, inline destructive error, `AppButton.filled` with loading + `AppButton.plain` mode switch; signed-in state as a profile section + destructive "Sign out" row. Validators, regex, `_submit`, `_busy`, auth calls unchanged. Removed: `Scaffold`, `TextFormField`, `IconButton`, Filled/Outlined/TextButton, `LahumaIconButton`, `GoogleFonts` inline styles, `Colors.*`.
- **Fixes from device check** — `AppProgressBar` track now full width; lists keep the translucent nav-bar inset (no explicit `padding` on scroll views inside `AppScaffold`, documented); transparent Android status bar (`AppTheme.applySystemChrome()` in `main.dart`).
- **Screen 2 · Home** — `AppScaffold.largeTitle` with the greeting as large title (collapses into the bar, Today-style), settings + account as trailing `AppIconButton`s; hero `ContinueReadingCard` on `AppCard` with the brand gradient, no coloured shadow / border, `AppProgressBar`, LTR-isolated percent, `play_fill`; shortcuts as 2 × 2 `FeatureCard` tiles whose height follows their text (no `childAspectRatio`), Settings-style `AppIconTile`s on system colours (raw hex removed); `SectionTitle`, `ProgressCard`, `SadaqahCard` restyled on tokens (LTR-isolated "N / M", system orange / red). Provider watches, progress URL, `push` / `go`, `GoalSheet.show` / `DedicationSheet.show` unchanged. Verified on device: light / dark, Arabic RTL / English LTR, swipe-back from right (RTL) and left (LTR) edges.
- **Fajr Call screens (new, built on the design system)** — `features/fajr_call/`: lists (`AppScaffold.largeTitle`, inset-grouped rows with `AppSwitch`, an original code-drawn lantern on the empty state that honours Reduce Motion), editor (`AppTextFormRow`, `AppSegmentedControl`, new `AppSliderRow` / `AppStepperRow` / `WeekdayChips` with VoiceOver adjustable semantics, contacts in a `ReorderableList` styled as an inset group with swipe-to-delete and undo toast, sticky filled save bar, discard confirmation), log (2 × 2 stat tiles, sessions per morning with attempt status runs and an awake toggle), full-screen wake list (opened from the notification, "Done" instead of a back chevron) and a permissions checklist. Times and numbers go through `ltr()` / `LtrText`. Widget tests cover Arabic / English × light / dark and 1.6× text. Settings is not converted yet, so its new "الفجر" row uses that screen's existing tiles.
- **Splash + onboarding** (branch `feature/splash-onboarding`) — Native launch screen via `flutter_native_splash` (dev dependency): the gold wordmark (160 pt, from `tools/generate_icon`) on the new `AppColors.splashBackground`, light / dark and Android 12+; `main()` decodes the Flutter copy first so the hand-over is pixel-identical. Animated splash: one 1.6 s timeline (a rub el hizb draws itself from its corners and settles with `AppMotion.springCurve`, a gold-leaf sweep crosses the wordmark, the tagline rises, a faint `StarLatticePainter`), three breathing stars only while `bootstrapProvider` is still running; it leaves when start-up is done and 1.6 s have passed (5 s at most), fading into Home or `/onboarding`. Notification launches skip the introduction; Reduce Motion shows the last frame. Introduction (`features/onboarding/`): seven `PageView` pages in the layout's direction, Skip / Next → Start, gold-rimmed page pill, 0.6× parallax, per-page sky wash, Mushaf frame corners around six living miniatures built from the features' own widgets (`CompassDial`, `KhatmaRing`, `BeadsPainter` + `CounterDisplay`, `PrayerSkyPainter`, the Mushaf's ayah rosettes and al-Fatiha text), each playing only while its page is current; last page sets language and theme. Flag `onboarding_completed_v1`; Settings → "Show the introduction again". The prayer times' first location prompt waits until the introduction was seen. New tokens: `splashBackground`, `splashGlow`, `splashGold`. `AppButton.trailingIcon` (mirrored in RTL). Tests: `splash_test.dart`, `onboarding_test.dart`. Screenshots: `docs/apple-redesign/screenshots/splash-onboarding-{ar,en}-{light,dark}.png` (widget-test renders with stand-in fonts: Segoe UI for Cairo, Amiri for Scheherazade New; Android/iOS draw the real ones).
- **`secondaryLabel` at WCAG AA** — Light mode was 62% ink: 3.2–3.7:1 on every surface it sits on (ivory, cells, wells, bars, accent-tinted rows), below the 4.5:1 AA needs for body text. Now 77% ink (`0xC42A3F38`): 4.6:1 at worst (accent-tinted rows on ivory, the introduction's washes), 5.2:1 on ivory, 5.6:1 on white; still clearly below `label` (12.7:1). Dark mode already passed (4.8:1 at worst) and is unchanged. The introduction's interim `supportingLabel` is gone. Still below AA, and left as they are: `tertiaryLabel` / `placeholder` (placeholders and hints) and the legacy `mutedLight` / `mutedDark` used by unconverted screens.
